# RelayQ 0.1.0

**中文** | [English](0.1.0.en.md)

[返回 README](../../README.md) · [GitHub Release](https://github.com/SuanLa/relayq/releases/tag/v0.1.0)

RelayQ 首个公开版本：基于 MySQL 的轻量级任务调度框架，提供 Spring Boot Starter。

## 主要功能

- 即时与延迟任务提交、基于 `biz_key` 的幂等防重
- 多实例任务抢占与异步执行
- 租约续期、超时回收与失败重试
- 死信管理、手动重投与执行审计
- Micrometer 指标、故障快照与优雅停机

## Maven 接入

已发布至 Maven Central：

```xml
<dependency>
    <groupId>io.github.suanla</groupId>
    <artifactId>relayq-spring-boot-starter</artifactId>
    <version>0.1.0</version>
</dependency>
```

## 运行环境

本版本使用 Java 21、Spring Boot 3.2.9 和 MySQL 8 进行开发与验证。

使用前，请按 README 初始化数据库并配置数据源。

## 语义与限制

- 提供 at-least-once 语义；业务 Handler 仍需保证幂等。
- 不保证严格 FIFO。
- 本轮 attempt=1 的校验结果不代表故障场景下的 exactly-once 保证。
- 性能结果仅适用于报告中的测试配置与负载，不代表框架容量上限。
- HTTP 提交延迟不等于任务端到端完成延迟。
