# RelayQ 0.1.0

[中文](0.1.0.zh-CN.md) | **English**

[Back to README (Chinese)](../../README.md) · [GitHub Release](https://github.com/SuanLa/relayq/releases/tag/v0.1.0)

The first public release of RelayQ: a lightweight, MySQL-backed task scheduling framework with a Spring Boot Starter.

## Features

- Immediate and delayed task submission with `biz_key`-based deduplication
- Task claiming across multiple instances and asynchronous execution
- Lease renewal, expired-task reclamation, and retries
- Dead-letter management, manual redrive, and execution auditing
- Micrometer metrics, diagnostic snapshots, and graceful shutdown

## Maven Dependency

Available on Maven Central:

```xml
<dependency>
    <groupId>io.github.suanla</groupId>
    <artifactId>relayq-spring-boot-starter</artifactId>
    <version>0.1.0</version>
</dependency>
```

## Runtime Environment

This release was developed and validated with Java 21, Spring Boot 3.2.9, and MySQL 8.

Initialize the database schema and configure the data source as described in the README before use.

## Semantics and Limitations

- Provides at-least-once semantics; business handlers must remain idempotent.
- Strict FIFO ordering is not guaranteed.
- The single-attempt results of this test do not imply exactly-once guarantees under failures.
- Performance results apply only to the documented configuration and workload; they do not establish the framework's maximum capacity.
- HTTP submission latency is not end-to-end task completion latency.
